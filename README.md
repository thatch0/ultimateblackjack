# Ultimate Black Jack v1.1
a version of blackjack that is playable in the console. I plan to add new features, such as betting and different modes

## How to Set Up
setting up is incredibly easy, but for those who lack computer literacy here are the step by step instructions
### Windows
- download the .py file
- make sure you have python installed
- open your command prompt
- type in "cd C:\Users\your_username\Downloads" and press enter (obviously replace "your_username" with your actual username
- then type "python3 ultimateblackjack.py" and enjoy
### Linux
- if you use Linux and you are genuinely stuck on how to run this, consider switching operating systems
